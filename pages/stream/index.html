Forge the stream

A funder streams PRL to a beneficiary at a fixed rate. Each tick is its own Taproot address that unlocks at start + i × tick interval (<lock> OP_CHECKLOCKTIMEVERIFY). Optionally revocable: the funder can claw back unmatured ticks later. Keys and secrets never leave this page.

Stream total: — fund each tick address

Send exactly the rate to each tick address. The funder's wallet pays these as ordinary PRL sends. Nothing streams until funded.

Stream descriptor

Hand this to the beneficiary (or save it). Anyone can re-derive every tick address from it and verify the funder funded the right ones — it is tamper-evident.

Claim matured ticks — one transaction

This step moves real PRL. The beneficiary imports their secret (mnemonic or WIF — never stored, never sent anywhere), ticks the matured funded ticks to sweep, and builds one batch-claim transaction. Exact fee math, every signature re-verified before broadcast.

Ticks to sweep

Matured, funded ticks are pre-ticked. For each ticked tick, supply its UTXO — scan via Blockbook or paste txid vout value lines (matched to ticked ticks in order).

Cancel stream — claw back unmatured ticks

This step moves real PRL. On revocable streams the funder sweeps unmatured ticks back in one transaction. Matured-but-unclaimed ticks stay claimable by the beneficiary. The cancel transaction carries nLockTime = the last selected tick's unlock, so it confirms only once that time passes — it pre-empts future claims, it does not claw back PRL today.

Ticks to claw back

Honest limits

  • Nothing streams until the funder actually sends PRL to each tick address — the stream is a plan until funded.
  • Maturity is read from Blockbook's latest block time (or your clock, labeled when it is). A claim broadcast before maturity will be rejected by the network.
  • Cancel sweeps only unmatured ticks and its transaction confirms only once the last selected tick's unlock passes — it pre-empts future claims, not today's funds.
  • Locks are unix timestamps; tick intervals are exact seconds. Test on testnet first. This is a streaming tool, not legal or tax advice.
